============================================================
=== Explanation: How the 'percentage' Argument is Passed ===
============================================================

This document explains the step-by-step journey of the progress percentage value from its calculation in the background network-checking thread to its final display on the GUI label. This process is managed by the Qt signal and slot mechanism, which allows for safe communication between different threads.

------------------------------------------
### The Core Concept: Push, Don't Pull ###
------------------------------------------

The 'percentage' argument is not actively "retrieved" or "pulled" by the GUI. Instead, it is "pushed" from the background thread via a signal and "delivered" by the Qt event loop directly into the GUI update function (the "slot") as an argument. This is the fundamental, thread-safe way that Qt communicates data between threads.

Here is the precise journey of the data.


------------------------------------------------------------
### Step 1: Calculation in the Background Network Thread ###
------------------------------------------------------------

It all starts deep inside the 'printer_network_checks_async.py' file, within the 'ping_printers_async' function...

# In printer_network_checks_async.py

def update_progress():
    # ...
    # The raw integer value (e.g., 5, 10, 11) is calculated here.
    progress_percentage = int((counter / ip_address_count) * 100) 
    
    # The callback function is called, passing this integer as its argument.
    if progress_callback:
        progress_callback(progress_percentage) 


---------------------------------------------------------------------
### Step 2: Signal Emission in the Worker Thread (program_gui.py) ###
---------------------------------------------------------------------

The 'progress_callback' function that gets called in Step 1 was defined inside the Worker's 'run' method in the GUI file.

# In the Worker's run() method

# This is the callback. 'percentage' here will be the value from Step 1.
progress_callback = lambda percentage: self.progress_percent.emit(percentage)

--> What happens: 
When 'progress_callback(5)' is executed, the lambda function runs. The value '5' is passed in as the 'percentage' argument.

--> The Key Moment: 
The command self.progress_percent.emit(5) is executed. This takes the integer value (5) and broadcasts it across the thread boundary as the "payload" of the 'progress_percent' signal.


------------------------------------------------------------------------
### Step 3: Signal Reception in the Main GUI Thread (program_gui.py) ###
------------------------------------------------------------------------

Before the background task ever started, you created a subscription in your 'run_check' method. This connection is always listening for the signal.

# In the run_check() method

self.worker.progress_percent.connect(self.update_progress_label)

--> What this line means: 
"Whenever the 'worker' object emits its 'progress_percent' signal, we want to automatically call the 'self.update_progress_label' method. Furthermore, take whatever value was emitted with the signal and pass it as the first argument to that method."


----------------------------------------------------------
### Step 4: Slot Execution in the GUI (program_gui.py) ###
----------------------------------------------------------

The main Qt event loop, which is always running in the main thread, receives the 'progress_percent' signal and its payload (the integer 5). It sees that the 'update_progress_label' method is subscribed to this signal.

def update_progress_label(self, percentage):
    """Updates the progress counter label with the percentage."""
    self.progress_counter_label.setText(f"{percentage}%")

--> What happens: 
The event loop invokes your 'update_progress_label' function.

--> Data Delivery: 
It takes the integer value (5) that was carried by the signal and automatically passes it into the function as the 'percentage' argument.

--> Final Action: 
Inside the function, the 'percentage' variable now holds the value 5. The final line of code formats this integer into the string "5%" and safely updates the GUI label.
